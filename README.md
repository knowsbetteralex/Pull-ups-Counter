# Pull-Up Counter v0.5

Android-приложение на Java для автоматического подсчёта подтягиваний по фронтальной камере.

## Возможности

- Camera2 без CameraX;
- MediaPipe Pose Landmarker Lite;
- отображение 33 точек скелета;
- анализ углов локтей и положения головы относительно перекладины;
- автомат состояний `WAITING -> DOWN -> GOING_UP -> UP -> GOING_DOWN`;
- автоматическое определение перекладины по кистям с уточнением по горизонтальному контрастному краю;
- ручная корректировка линии перекладины;
- текущая попытка и дневной итог в одном крупном индикаторе `попытка / сегодня`;
- анимированное подтверждение каждого нового повторения: большое полупрозрачное число появляется по центру и уменьшается, перемещаясь в счётчик;
- крупные полупрозрачные команды внизу изображения;
- локальная история всех непустых попыток по дням;
- отдельный экран истории с итогами и временем попыток;
- опциональная TTS-озвучка текущего счёта;
- отдельная опциональная TTS-озвучка рекомендаций тренера;
- оба голосовых режима выключены по умолчанию;
- adaptive launcher icon и короткая заставка;
- локальное хранение истории через `SQLiteOpenHelper`.

## Главный экран

В центре верхней панели отображается:

```text
ПОПЫТКА / СЕГОДНЯ
3 / 27
```

Левое число — текущая попытка, правое — сумма подтягиваний за текущий календарный день. Нажатие на этот блок открывает историю.

В строке управления находятся:

- **Авто** — повторный автоматический поиск перекладины;
- **Линия** — ручная корректировка;
- **Новая** — завершить текущую попытку и начать новую, не сбрасывая дневной итог;
- значок динамика — озвучка нового количества повторений;
- значок сообщения — голосовые рекомендации.

Активные голосовые иконки подсвечиваются зелёным. После запуска приложения оба режима выключены.

## Анимация счёта

При каждом засчитанном подтягивании:

1. новое количество текущей попытки появляется крупным полупрозрачным числом в центре экрана;
2. число кратко акцентируется;
3. затем уменьшается и перемещается в левую часть верхнего индикатора;
4. после завершения анимации обновляется `попытка / сегодня`.

Запись в SQLite выполняется сразу при зачёте повторения и не зависит от завершения анимации.

## Голосовой счёт

При включённой иконке динамика Android `TextToSpeech` произносит новое количество после каждого засчитанного повторения.

Например:

```text
1
2
3
...
```

Счёт имеет приоритет: новое повторение может прервать менее важную голосовую рекомендацию.

## Голосовые рекомендации

Отдельный переключатель включает редкие рекомендации по значимым состояниям. Сейчас предусмотрены фразы:

- «Перекладина найдена»;
- «Перекладина задана»;
- «Можно начинать» после устойчивой нижней точки;
- «Опуститесь ниже и распрямите руки», если стартовая нижняя точка не достигнута;
- «Опуститесь ниже», если спуск затянулся и нижняя точка не достигнута;
- «Поднимитесь выше», если подъём затянулся около верхней точки;
- подсказки для автоматической и ручной калибровки.

Между рекомендациями действует пауза, чтобы TTS не повторял подсказки на каждом кадре.

Для TTS сначала запрашивается русский голос `ru-RU`. Если он недоступен, используется язык устройства.

## Как считается попытка

Одна попытка — серия подтягиваний между нажатиями **«Новая»**.

- первое повторение создаёт запись попытки в SQLite;
- каждое следующее сразу обновляет запись;
- попытки с 0 повторений в историю не попадают;
- новая попытка обнуляет только левую часть счётчика;
- дневной итог и история сохраняются;
- при переходе через полночь автоматически начинается новый дневной счёт.

## История

История группируется по календарным дням устройства. Для каждого дня показаны:

- суммарное число подтягиваний;
- все сохранённые попытки;
- время начала каждой попытки;
- количество повторений.

База: `pullup_history.db`.

## Определение перекладины

При старте приложение включает автопоиск:

1. человек берётся за перекладину и висит на прямых руках;
2. MediaPipe определяет кисти;
3. `AutoBarDetector` ищет горизонтальную границу рядом с высотой хвата;
4. несколько наблюдений стабилизируются;
5. найденная линия фиксируется.

Автоматическая линия зелёная и помечается `AUTO`. Ручная — янтарная и помечается `MANUAL`.

## Условия зачёта

Нижняя точка:

- средний угол локтей больше примерно 155°;
- плечи заметно ниже линии перекладины;
- положение стабильно несколько кадров.

Верхняя точка:

- средний угол локтей меньше примерно 85°;
- центр рта выше линии перекладины с небольшим допуском;
- положение стабильно несколько кадров.

Повтор засчитывается только после последовательности `DOWN -> UP`. Следующий повтор невозможен до возврата в нижнюю точку.

## Основные классы

- `MainActivity` — камера, UI, анимация счёта, TTS, калибровка и статистика;
- `Camera2Controller` — захват кадров;
- `PoseEngine` — MediaPipe Pose Landmarker;
- `PullupDetector` — автомат состояний и счёт повторений;
- `AutoBarDetector` — автоматический поиск перекладины;
- `OverlayView` — скелет и линия перекладины;
- `StatsStore` — SQLite-история;
- `HistoryActivity` — экран истории;
- `SplashActivity` — стартовая анимация.

## Сборка

Требования:

- Android SDK 35;
- minSdk 24;
- Java 17;
- Gradle 8.13;
- Android Gradle Plugin 8.11.0;
- MediaPipe Tasks Vision 0.10.29.

При первом `preBuild` Gradle автоматически скачивает `pose_landmarker_lite.task`.

```bash
gradle assembleDebug
```

APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## GitHub Actions

Workflow `.github/workflows/build-apk.yml` собирает debug APK на push/PR в `main` и публикует artifact `PullUpCounter-debug`.

Путь в GitHub: **Actions -> Build APK -> последний зелёный запуск -> Artifacts -> PullUpCounter-debug**.
