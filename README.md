# Pull-Up Counter v0.4

Android-приложение на Java для автоматического подсчёта подтягиваний по фронтальной камере.

## Возможности

- Camera2 без CameraX;
- MediaPipe Pose Landmarker Lite;
- отображение 33 точек скелета поверх изображения;
- анализ углов обоих локтей и положения головы относительно перекладины;
- автомат состояний `WAITING -> DOWN -> GOING_UP -> UP -> GOING_DOWN`;
- автоматическое определение перекладины по положению кистей с уточнением по горизонтальному контрастному краю кадра;
- ручная корректировка линии перекладины касанием по изображению;
- счётчик повторений текущей попытки;
- суммарное число подтягиваний за текущий день в шапке;
- локальная история всех непустых попыток по дням;
- отдельный экран истории: итог дня, время каждой попытки и количество повторений;
- собственная adaptive launcher icon;
- короткая анимированная заставка при запуске;
- полностью локальное хранение истории через `SQLiteOpenHelper`.

## Как считается попытка

Одна попытка — это серия подтягиваний между запусками кнопки **«Новая попытка»**.

- первая засчитанная репетиция создаёт запись попытки в SQLite;
- каждое следующее повторение сразу обновляет эту запись;
- попытки с 0 повторений в историю не попадают;
- **«Новая попытка»** обнуляет только текущий счётчик, но не дневной итог и не историю;
- положение перекладины при этом сохраняется;
- если приложение остаётся открытым при переходе через полночь, автоматически начинается новый дневной счёт.

## Дневная статистика и история

В правой части верхней карточки отображается блок **«Сегодня»**. Нажатие на него открывает историю.

История группируется по календарным дням устройства. Для каждого дня показаны:

- суммарное число подтягиваний;
- все сохранённые попытки;
- время начала каждой попытки;
- количество повторений в каждой попытке.

База данных: `pullup_history.db`.

## Определение перекладины

При старте приложение включает автопоиск:

1. человек берётся за перекладину и спокойно висит на прямых руках;
2. MediaPipe определяет положение кистей;
3. `AutoBarDetector` ищет горизонтальную границу рядом с предполагаемой высотой хвата;
4. несколько последовательных наблюдений стабилизируются;
5. найденная линия фиксируется как перекладина.

Автоматическая линия показывается зелёным и помечается `AUTO`.

Если автоматическое определение неточное, кнопка **«Линия»** включает ручную корректировку. Ручная линия отображается янтарным и помечается `MANUAL`.

Кнопка **«Авто»** повторно запускает автоматическую калибровку.

## Условия зачёта

Нижняя точка:

- средний угол локтей больше примерно 155°;
- плечи заметно ниже линии перекладины;
- положение стабильно несколько кадров.

Верхняя точка:

- средний угол локтей меньше примерно 85°;
- центр рта поднялся выше линии перекладины с небольшим допуском;
- положение стабильно несколько кадров.

Повтор засчитывается только после последовательности `DOWN -> UP`. Следующий повтор невозможен, пока человек снова не вернётся в нижнюю точку.

## Структура

Основные классы:

- `MainActivity` — камера, UI, калибровка, счётчик и запись статистики;
- `Camera2Controller` — захват кадров;
- `PoseEngine` — MediaPipe Pose Landmarker;
- `PullupDetector` — автомат состояний и подсчёт повторений;
- `AutoBarDetector` — автоматический поиск перекладины;
- `OverlayView` — скелет, линия перекладины и подсказки;
- `StatsStore` — SQLite-история попыток и дневные суммы;
- `HistoryActivity` — экран истории;
- `SplashActivity` — короткая стартовая анимация.

## Сборка

Требования:

- Android SDK 35;
- minSdk 24;
- Java 17;
- Gradle 8.13;
- Android Gradle Plugin 8.11.0;
- MediaPipe Tasks Vision 0.10.29.

При первом `preBuild` Gradle автоматически скачивает `pose_landmarker_lite.task` в `app/src/main/assets/`.

Локальная сборка:

```bash
gradle assembleDebug
```

APK создаётся в:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## GitHub Actions

Workflow `.github/workflows/build-apk.yml` запускается на push в `main`, pull request в `main` и вручную через `workflow_dispatch`.

Он:

1. настраивает JDK 17;
2. поднимает Gradle 8.13;
3. выполняет `assembleDebug`;
4. публикует APK как artifact `PullUpCounter-debug`.

В GitHub готовую сборку можно найти через **Actions -> Build APK -> последний зелёный запуск -> Artifacts -> PullUpCounter-debug**.
