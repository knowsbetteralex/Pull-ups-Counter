# Pull-Up Counter v0.6

Android-приложение на Java для автоматического подсчёта подтягиваний по фронтальной камере.

## Возможности

- Camera2 без CameraX;
- MediaPipe Pose Landmarker Lite;
- отображение 33 точек скелета;
- автоматический подсчёт подтягиваний по углам локтей и положению головы относительно перекладины;
- автоматическое определение перекладины с ручной корректировкой;
- текущая попытка и дневной итог в одном индикаторе `попытка / сегодня`;
- анимированное подтверждение каждого нового повторения;
- крупные команды внизу изображения;
- опциональная TTS-озвучка счёта и отдельные голосовые рекомендации;
- локальная история всех непустых попыток по дням;
- Android Auto Backup истории;
- ручной экспорт/импорт истории в JSON через системный файловый диалог;
- возможность сохранить резервную копию локально или в облачный файловый провайдер, например Google Drive;
- adaptive launcher icon и короткая заставка.

## Главный экран

В центре верхней панели отображается:

```text
ПОПЫТКА / СЕГОДНЯ
3 / 27
```

Левое число — текущая попытка, правое — сумма за текущий календарный день.

Кнопки:

- **Авто** — повторный поиск перекладины;
- **Линия** — ручная корректировка;
- **Новая** — новая попытка без сброса дневной суммы;
- динамик — TTS-счёт;
- иконка рекомендаций — голосовой тренер.

Оба TTS-режима выключены по умолчанию.

## История

Экран истории открывается нажатием на `попытка / сегодня`.

Для каждого дня отображаются:

- суммарное количество подтягиваний;
- все попытки;
- время начала каждой попытки;
- количество повторений.

История хранится в SQLite:

```text
pullup_history.db
```

## Резервное копирование

### Android Auto Backup

В manifest включён `android:allowBackup="true"`.

Для Android 12+ используется:

```text
res/xml/backup_rules.xml
```

Для старых версий Android:

```text
res/xml/backup_rules_legacy.xml
```

В системную резервную копию включается база `pullup_history.db`. Если на устройстве и аккаунте работает Android Backup, система может автоматически восстановить историю после переустановки приложения или переноса на новое устройство.

Auto Backup управляется Android и выполняется не сразу после каждого подтягивания, поэтому для важных данных рекомендуется дополнительно пользоваться ручной копией.

## Ручная резервная копия

Вверху экрана истории есть две кнопки:

- **Сохранить копию**;
- **Восстановить**.

### Сохранение

**Сохранить копию** открывает Android Storage Access Framework (`ACTION_CREATE_DOCUMENT`).

Пример имени:

```text
PullUpCounter_backup_2026-10-21_09-45.json
```

Файл можно сохранить:

- в память телефона;
- на SD-карту;
- в Google Drive, если он доступен в системном файловом диалоге;
- в другой установленный DocumentsProvider.

Приложению не требуется разрешение на доступ ко всей памяти.

### Формат JSON

Формат имеет собственную версию:

```json
{
  "format": "pullup-counter-backup",
  "version": 1,
  "exportedAt": 1792572300000,
  "attempts": [
    {
      "startedAt": 1792568700000,
      "reps": 8
    }
  ]
}
```

Это позволяет менять внутреннюю структуру SQLite в будущих версиях приложения, сохраняя совместимость с резервными копиями.

### Восстановление

**Восстановить** открывает `ACTION_OPEN_DOCUMENT` и позволяет выбрать JSON-файл.

После чтения предлагаются варианты:

- **Объединить** — рекомендуемый вариант. Текущая история остаётся, новые попытки добавляются;
- **Заменить** — вся текущая история удаляется и заменяется данными из файла.

При объединении защита от дублей работает по точному времени начала попытки. Если попытка уже существует, но в резервной копии у неё больше повторений, сохраняется большее значение.

Перед режимом **Заменить** приложение показывает дополнительное подтверждение.

## Подсчёт

Нижняя точка:

- средний угол локтей больше примерно 150°;
- плечи находятся заметно ниже перекладины;
- положение удерживается несколько кадров.

Верхняя точка:

- средний угол локтей меньше примерно 85°;
- центр рта выше линии перекладины;
- положение стабильно несколько кадров.

Повтор засчитывается после последовательности `DOWN -> UP`.

## Основные классы

- `MainActivity` — камера, UI, TTS, анимация счёта и текущая попытка;
- `PullupDetector` — подсчёт повторений;
- `AutoBarDetector` — определение перекладины;
- `OverlayView` — скелет и линия;
- `StatsStore` — SQLite, JSON export/import и объединение резервных копий;
- `HistoryActivity` — история и интерфейс резервных копий;
- `SplashActivity` — заставка.
